BAC is easy — النسخة التجريبية الحالية
=====================================

محتويات المجلد:
- index.html: واجهة التطبيق.
- main.js: تشغيل نافذة Electron وإدارة صلاحياتها.
- package.json: إعدادات المشروع واعتمادياته وأوامر التشغيل والبناء.
- icon.png: أيقونة التطبيق.

بطاقة البداية:
تحتوي على الاسم وسنة البكالوريا والشعبة والهدف الدراسي واختيار الثيم.
لا يوجد حقل لتاريخ الامتحان في بطاقة البداية.

العد التنازلي:
يُدخل تاريخ الامتحان لاحقاً من صفحة الإعدادات، وليس من بطاقة البداية.

التشغيل على Windows:
1. ثبّت Node.js إصدار LTS من https://nodejs.org/
2. افتح هذا المجلد في Terminal أو PowerShell.
3. نفّذ: npm install
4. بعد انتهاء التثبيت نفّذ: npm start

إنشاء ملف تثبيت Windows (بعد اختبار التطبيق):
نفّذ: npm run build

ملاحظات:
- لا ترفع مجلد node_modules إلى GitHub؛ يتم إنشاؤه بواسطة npm install.
- إذا أنشأ npm ملف package-lock.json، احتفظ به وارفعه مع المشروع.
- لا تضع مفاتيح API أو كلمات المرور داخل ملفات المشروع أو في GitHub.
- هذه نسخة تجريبية؛ يجب اختبارها على Windows، بما في ذلك الحفظ والتذكيرات والميكروفون واتصالات مزودي الذكاء الاصطناعي.
- لا يحتوي هذا المجلد على النسخة القديمة أو ملفات احتياطية قديمة.
